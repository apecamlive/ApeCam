# ADR 003 — Siaran dari browser (LiveKit)

Status: **Tertunda — butuh akun LiveKit (S0-2)** · Spike S3

Yang harus diuji setelah proyek LiveKit dibuat:

- Publish kamera + mic di Chrome, Safari, Firefox, iOS Safari, dan Android Chrome.
- Screen share seluruh layar / window / tab + audio sistem (Chrome/Edge).
- Screen share + camera bubble (dua track), dilihat dari sisi viewer.

Hasil akhirnya berupa matriks dukungan browser.
